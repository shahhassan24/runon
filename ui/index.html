Welcome to Runon

Begin anywhere. Don’t stop. Runon is for freewriting: writing without stopping for a set time, so you find out what you actually think.

  • Pick something to write aboutA decision, a problem at work, a new idea.
  • Set the timerClick the time in the toolbar, choose how long, and click Start.
  • Keep writingThe toolbar fades and a line grows along the bottom. When the toolbar comes back, you’re done. Want no going back? Turn off Allow Backspace.
  • Private by designYour writing stays on this computer, in Documents/Runon. It only leaves if you choose Chat.
